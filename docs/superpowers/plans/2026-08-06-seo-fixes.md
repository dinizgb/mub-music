# SEO Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the metadata-first SEO rebuild from `docs/superpowers/specs/2026-08-06-seo-fixes-design.md`.

**Architecture:** Shared `lib/seo/` helpers power App Router `metadata` / `generateMetadata`, real JSON-LD, sitemaps, and robots. Delete unused `services/SEO/*SEOConstructor*` files.

**Tech Stack:** Next.js App Router Metadata API, TypeScript, Jest, existing GraphQL `fetchQuery` services, i18n.

## Global Constraints

- Preferred URL: `https://{NEXT_PUBLIC_ENV_DOMAIN}/…` with trailing slash; apex host from env (production: `mubmusic.com`).
- Never emit `https://undefined/…`; assert domain in `siteConfig`.
- Metadata API only for crawlable meta; no legacy constructor `<meta>` tags.
- JSON-LD: real CMS data only; omit unknown fields; never fabricate offers/reviews/GTIN.
- Home title: `Mub Music | Reviews, Offers & Specs`; home description: existing `i18n.home.headline` copy.
- Follow `rules.md` testing requirements (≥90% on new `lib/seo` modules).
- Package manager: npm. Branch: `bugfix/seo-issues`.
